# autoconnect

## Смысл фичи
Пользователь в главном меню может нажать на `happ` или `incy` и сразу импортируется автоматически подписка в приложение


`LINK_SECRET` — ключ шифрования. Из него через SHA-256 выводится ключ AES-256,
которым шифруется адрес подписки: в ссылке на страницу лежит только токен `t`,
поэтому пользователь не может прочитать подписку из кнопки Telegram.

Если `AUTO_CONNECT_SUB` или `LINK_SECRET` пустые, Happ-кнопка ведёт на исходную
ссылку подписки, а Incy-кнопка не показывается.

Happ получает ссылку через `happ://crypt5/` (API `crypto.happ.su`). Если API
недоступен, страница отдаёт обычный `happ://add/`: подключение важнее скрытности.

В Incy-ссылку передаётся имя подписки из `PROVIDER_NAME` — оно показывается
в списке подписок приложения. Пустое значение означает подписку без имени.
